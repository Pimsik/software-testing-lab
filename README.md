# software-testing-lab
Практична робота з автоматизованого тестування вебсайту за допомогою JavaScript та Playwright
# Практична робота: Створення автоматизованого тесту за допомогою штучного інтелекту та публікація коду на GitHub

## Тестований вебсайт
- **Назва:** Українська Вікіпедія
- **Посилання:** https://uk.wikipedia.org

## Опис трьох автоматизованих перевірок
Скрипт `test.js` автоматично запускає браузер Chromium та виконує три основні перевірки:
1. **Перевірка заголовка сторінки:** Відкриває головну сторінку сайту та перевіряє, чи містить її заголовок слово «Вікіпедія».
2. **Перевірка наявності та заповнення поля пошуку:** Знаходить поле пошуку на головній сторінці, перевіряє його видимість і вводить пошуковий запит «Автоматизоване тестування».
3. **Перевірка переходу на іншу сторінку:** Натискає клавішу Enter, очікує переходу на сторінку статті та перевіряє, чи відповідає заголовок відкритої сторінки пошуковому запиту.

## Інструкція із запуску тесту
1. Встановіть Node.js та Visual Studio Code.
2. Завантажте файл `test.js` у окрему папку проєкту.
3. Відкрийте термінал у папці проєкту та виконайте команди для встановлення бібліотеки Playwright:
   - `npm init -y`
   - `npm install playwright`
   - `npx playwright install chromium`
4. Запустіть тест командою:
   - `node test.js`
